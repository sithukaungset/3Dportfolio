# 🚀 Road to AGI — 3D Portfolio

A cyberpunk-inspired 3D portfolio website built with **Three.js** and **Vite**, featuring realistic procedural planets, cursor-reactive parallax, and an AI neural network cursor effect.

🔗 **Live:** [sithukaungset.github.io/3Dportfolio](https://sithukaungset.github.io/3Dportfolio/)

---

## ✨ Features

### 3D Scene
- 🪐 **Realistic procedural planets** — Earth, Mars, Gas Giant with ring, Ice Planet, Hero Planet with Saturn ring + orbiting moons
- 🌕 **Textured Moon** with normal mapping
- 🕳️ **Black Hole** with accretion disk and photon ring
- ⭐ **400 twinkling stars** in deep black space
- 🎯 **Cursor parallax** — entire 3D scene reacts to mouse movement (Lusion-style)

### UI/UX
- 🖱️ **AI Neural Network cursor** — floating nodes, connection lines, hex scan ring, data stream trail
- 📸 **Photo lightbox** — click any image to view full-screen
- 🎬 **Scroll-triggered animations** — elements reveal as you scroll
- 📱 **Fully responsive** — optimized for mobile and desktop
- 🌀 **CRT scanline overlay** + glitch effect on hero hover

### Content
- 📝 About section with portrait and stats
- 🖼️ Horizontal scrolling photo gallery (14 photos)
- 💼 Featured projects with tech tags
- 📄 Publications with paper screenshots (IEEE TSC, KICS, MSc Thesis)
- 🔬 NRF Korea research projects with images
- 🎖️ Microsoft Certifications grid with badge images
- 📊 Technical assessments timeline

## 🚀 Getting Started

```bash
# Clone
git clone https://github.com/sithukaungset/3Dportfolio.git
cd 3Dportfolio

# Install
npm install

# Dev server
npm run dev

# Build
npm run build
```
